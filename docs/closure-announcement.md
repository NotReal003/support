# Closure Announcement

Hey @everyone,

After being operational for over a year, our domain notreal003.org will expire on 28 June 2026. As a result, the website and services currently running under this domain may no longer be available after that date.

- We have added an Account Deletion option to the request page. If you previously signed in and would like to delete your account, please visit: [request-notreal003.pages.dev/profile](https://request-notreal003.pages.dev/profile) and select "Account Deletion". Deletion requests are processed automatically within 24 hours.

- [Sentralia](https://sentralia.pages.dev) will be open-sourced before 28 June 2026. Additional details, including the repository, licensing, and release information, will be announced soon.

::: tip OPEN SOURCE
As of June 28, 2026, Sentralia is officially open source. You can explore the source code and contribute to the project on GitHub: https://github.com/NotReal003/sentralia.
:::
Thank you for staying with us!
